## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability in FR_UNI, please report it by following these steps:

Email the Developer:
Send an email to [fr.root85@gmail.com] with the subject line "Security Vulnerability Report: FR_UNI."

Provide Detailed Information:
Include a clear description of the vulnerability, steps to reproduce it, and any relevant code snippets or logs.

Allow Time for Response:
We aim to acknowledge receipt of your report within 48 hours and provide a resolution timeline if applicable.

Responsible Disclosure:
Please do not publicly disclose the vulnerability until we have addressed it.

Your efforts to improve the security of FR_UNI are greatly appreciated.
